# Access Control — DRAFT, SECURITY APPROVAL REQUIRED

1. Grant roles and permissions by least privilege and scope. Protected API operations evaluate role, ownership, institution boundary, entitlement and content policy on the server.
2. Require MFA for administrators and recent step-up for grants, refunds, policy changes, domain approvals and research releases.
3. Use independent approval for high-risk changes and log actor, action, reason, correlation ID and before/after fingerprints.
4. Review access periodically; revoke terminated or expired assignments promptly; test deny-by-default paths.

Open decisions: review cadence, emergency access owner, service-account inventory and separation-of-duties exceptions.
